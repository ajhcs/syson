# Rust runtime dependency notices

This Rust port preserves the original SysON LICENSE, LICENSE-LGPL and NOTICE at repository root. Ported source attribution remains in each translated file. The selected standard-library resources retain their original LGPL-3.0-only obligations; this file does not relicense them.

The initial Rust model/UI runtime has five active registry dependencies, confirmed by `cargo tree --offline --edges normal --manifest-path rust/crates/syson-web/Cargo.toml`: serde_json1.0.151, serde_core1.0.229, itoa1.0.18, memchr2.8.3 and zmij1.0.23. Their actual supplied license texts, including original copyright statements, are retained unmodified in `third-party/<crate>/`; hashes and source-manifest hashes are in `third-party/manifest.json`. The MIT option is selected for these distributions (memchr allows MIT or Unlicense; serde_json/core/itoa allow MIT or Apache2.0; zmij is MIT). Alternative supplied texts are preserved as evidence, not removed. Cargo.lock contains additional inactive cfg/derive metadata; it is not an active runtime component list. New targets/features or dependencies require a fresh closure/notice review.

When distributing a compiled WASM/native artifact, include this file, the actual corresponding license texts, root SysON notices and access to the modified EPL source, together with a precise source revision and dependency lockfile. Preview preparation copies these notices alongside the local WASM artifact. Keeping notices in source alone is insufficient if an artifact package omits them. This is the audited initial Rust dependency closure, not legal clearance or complete transitive licensing for the upstream Java/TypeScript reference product. Syside and inherited Sirius dependency provenance remain unresolved in the source audit.
