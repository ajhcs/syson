# Semantic/model re-review

This pass binds 26 assigned published PR heads and 95 source/test files to immutable Git blobs. It uses the central 87-PR inventory; rollups and stacked snapshots are not counted as unique implemented features. Absent or prunable legacy worktrees were not used as source authority. The reviewer performed source inspection only: no compiler, runtime, browser, database, network, source edit, commit or publication.

Two new defects have root-run counterexamples. A literal vendor object with the serde private Number key becomes numeric123 in the Value-backed model boundary. With raw_value enabled, the same family of reserved-key interpretation can turn a vendor string into an indexed Namespace that never physically existed as a node in the JSON input. The latter was reproduced against the exact retained C01g release binary. Full original runtime artifacts remain outside this packet; findings.json binds their paths/hashes and states the distinct execution scope.

The legacy ResourceSet name resolver also follows arbitrarily long acyclic conjugation-reference chains recursively, without a work/depth/cancellation bound. This is source-confirmed risk, not a reviewer-run crash or measured stack threshold. F46's separate iterative name API does not repair that older path.

None of these source observations is presented as a measured latency regression. F47's allocation issue cross-references the parser/interchange review's existing F33/F34 allocation-before-guard family.

Existing M06/I03/I06, M10/M07 and related owners receive the new regressions and caller gates. Bundle admission, history, validation allocation and cancellation gaps augment existing tasks. Root will assign Rxx IDs and dependency stages; these proposals are not implementation work or newly published PRs.
