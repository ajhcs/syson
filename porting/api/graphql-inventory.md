# SysON project journey API inventory

This inventory gives the Rust port a source map for creating and opening a project, importing a document or project archive, finding model elements and views, editing a text property, and downloading a project. It covers selected operations on those paths. The broader [client-operation inventory (#273)](https://github.com/ajhcs/syson/issues/273) remains open for the other application routes, diagrams and editors, mutations, and capability-dependent contributions.

## Reference and transport

- **Release source.** The SysON 2026.9.3 artifact identifies SysON commit [`b380dada415ce05155150f23cb3b74ae21cc45e4`](https://github.com/eclipse-syson/syson/tree/b380dada415ce05155150f23cb3b74ae21cc45e4). The release ships Sirius Web 2026.9.3. The corresponding Sirius Web tag points to [`3191e2b8990373afee3415f6b26f8c5039a28321`](https://github.com/eclipse-sirius/sirius-web/tree/3191e2b8990373afee3415f6b26f8c5039a28321). SysON mounts `SiriusWebApplication` with its extensions. Sirius Web registers the project routes, Explorer, Views Explorer, and Details in its default extension registry. [SysON entry point](https://github.com/eclipse-syson/syson/blob/b380dada415ce05155150f23cb3b74ae21cc45e4/frontend/syson/src/index.tsx#L60-L71), [application composition](https://github.com/eclipse-sirius/sirius-web/blob/3191e2b8990373afee3415f6b26f8c5039a28321/packages/sirius-web/frontend/sirius-web-application/src/application/SiriusWebApplication.tsx#L57-L70), [registered views](https://github.com/eclipse-sirius/sirius-web/blob/3191e2b8990373afee3415f6b26f8c5039a28321/packages/sirius-web/frontend/sirius-web-application/src/extension/DefaultExtensionRegistry.tsx#L189-L218), [registered routes](https://github.com/eclipse-sirius/sirius-web/blob/3191e2b8990373afee3415f6b26f8c5039a28321/packages/sirius-web/frontend/sirius-web-application/src/extension/DefaultExtensionRegistry.tsx#L682-L713).
- **Port source.** The Rust comparison baseline is SysON [`6ba2ac64e6b16ee2b05752ad55395eebb87d4910`](https://github.com/eclipse-syson/syson/tree/6ba2ac64e6b16ee2b05752ad55395eebb87d4910). The checked-in audit records 125 changed paths between that pin and the release source label. The release artifact and version labels identify the observed deployment. Source-to-artifact reproducibility and contract equivalence to the port pin still need separate evidence. [Native reference audit](../audits/20261026/README.md).
- **Transport.** Apollo sends queries and ordinary mutations to `/api/graphql` and subscriptions over WebSocket `/subscriptions`. The two file uploads send multipart GraphQL to `POST /api/graphql/upload`, with the literal map `{"0":"variables.file"}`. The server recognizes that map and inserts the file into `variables.input.file` before executing the mutation. Project download uses its own HTTP GET controller. [Apollo links](https://github.com/eclipse-sirius/sirius-web/blob/3191e2b8990373afee3415f6b26f8c5039a28321/packages/sirius-web/frontend/sirius-web-application/src/graphql/useCreateApolloClient.ts#L46-L97), [multipart helper](https://github.com/eclipse-sirius/sirius-web/blob/3191e2b8990373afee3415f6b26f8c5039a28321/packages/sirius-web/frontend/sirius-web-application/src/core/sendFile.ts#L14-L35), [server multipart mapping](https://github.com/eclipse-sirius/sirius-web/blob/3191e2b8990373afee3415f6b26f8c5039a28321/packages/web/backend/sirius-components-graphql/src/main/java/org/eclipse/sirius/components/graphql/controllers/GraphQLController.java#L275-L294).

## Observed release behavior

The [archive experiment (#289)](https://github.com/ajhcs/syson/pull/289) ran against the official SysON 2026.9.3 JAR, SHA-256 `85c031352695d6ac8f059f0215ca493c58a16805a111233998dd443d6990c9e1`. Its harness created the synthetic project with `createProject`, queried its editing context, and received `UploadDocumentSuccessPayload` when it uploaded a SysML document. The browser opened the project, used Explorer to create and open a General View, and clicked **Download project**. The recorded GET returned HTTP 200 and a 3,210-byte ZIP attachment. The trace recorded the download HTTP exchange and UI actions. The GraphQL operation names used by that UI come from the static call sites above. Live browser GraphQL capture, a Details edit, archive upload, and behavior after a backend restart remain to be verified for this slice.
