# C01h: actual native template discovery and typed choices

The Rust reader consumes ten actual anonymous, read-only native GraphQL
observations and preserves the entire capture Value, exact raw body strings,
unknown fields/numbers, array order, headers and PageInfo. It derives only the
source-defined template/control choice classification and bound lookup. The exact
native fixture is committed once under the crate tests; `fixture-links.json`
identifies other retained copies without duplicating it here.

Observed native data has four ordinary templates in the all-template catalogue.
The large browser page includes those template choices plus upload/browse controls.
Both small-browser requests return GraphQL errors. The later small modal page is
successful but empty, retaining count four and its original cursors/flags. Invalid
context and invalid page-type requests also fail. These four errors are preserved
as error observations with null choices, rather than empty successful catalogues.
No pagination reconstruction or correction is implemented.

Only `upload-project` and `browse-all-project-templates`, in PROJECT_BROWSER,
select controls. Blank projects remain real templates; an empty label does not
classify anything. The same IDs in another context remain ordinary template IDs
if observed there. Unknown or duplicate/ambiguous selections refuse. Projection
accepts observation/choice IDs and performs lookup internally, so callers cannot
publish an invented public Choice. Selected nullable cursor fields must exist,
with explicit null/string distinguished from omission.

`captures/c01h-01/` retains the original eight-test, formatting, Clippy and build
PASS with historical source. Independent review then found the public projection
bypass and missing-nullable-cursor gaps. `captures/c01h-02/` runs their two isolated
regressions, formatting, all-target Clippy and build on final source. The original
eight tests were not replayed; this is not a full ten-test rerun claim. All ten
final captured inputs match committed bytes. Final independent review accepted
the corrected hashes in `review-disposition.json`.

`templates-cli-01/` retains eleven actual CLI cases: five successful projections
preserve the whole capture Value and produce the correct template/blank/upload/
browse selection; six usage/input/symlink/unknown/failed-context/wrong-context
refusals produce no stdout. Raw streams and the executed runner remain intact.
`templates-native-01/` retains exact queries, native receipt, configuration,
startup/query logs and executed runner. The fresh derived reference is identified
by SHA256; all owned processes stopped and inputs stayed unchanged. Diagnostic
mappings were enabled only on the separate loopback context recorded in the
capture. No authentication, mutation, browser, project creation or library-loading
journey is credited by these reads.

`source-provenance.json` remains frozen historical input; `source-bindings.json`
adds immutable resolver/provider/frontend source references. Actual activation is
separate: the observed catalogue does not prove every conditional provider,
representation description or frontend extension is active. The code preserves
observed image URLs exactly, including the native prefix, without URL rewriting.
Required library metadata stays opaque to this family; C01g owns library work.

Input/output are bounded to 8 MiB with bounded rows/headers/IDs and incremental
counting serialization. Full Value preservation does not promise original object
member serialization order; body_utf8 strings remain byte-exact. No reader result
attests that supplied capture provenance is true. The source author performed
only source editing/formatting and read-only metadata/hash inspection. Native
startup, queries, Rust compilation/tests and actual CLI execution were root-owned.

Final production is 300 Rust lines; tests 377, query manifest 133, frozen source
provenance 31 and manifest 12 total 853 conservative authored lines, within 400/900.
Generated fixture/lock, prose and retained execution evidence are separate review
material. C01, B23, U03, independent source/build binding, template instantiation,
provider/extension activation and browser/UI/UX acceptance remain OPEN.
