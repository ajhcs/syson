# RR01 bounded literal-safe JSON foundation

The new standalone Rust crate parses literal JSON into a private ordered tree while retaining the exact borrowed input carrier. Generic Value deserialization is never used for objects. Ordinary private Number/RawValue keys remain ordinary object keys; strings containing node-shaped JSON cannot create physical nodes. Duplicate decoded keys explicitly refuse. Byte/depth/value/key/scalar-copy limits run before owned tree construction. Conversion returns `(Value, original_carrier)`; lexical object ordering in Value is explicit and raw/tree remain authoritative.

Complete strict borrowed RawValue syntax validation protects the private numeric conversion path. The exact pinned doc-hidden serde_json constructor preserves source numeric lexemes including -0, trailing decimal zeroes, exponent spelling and extreme magnitudes. No arbitrary public Node can be passed into this private converter. Pinned-source proof is retained in SOURCE-PROPOSAL.json. All 11 registry version/checksum tuples were already present in the baseline; no registry package/version was added.

Root's first offline capture passed all 11 regressions and formatting, then failed Clippy's manual-is-multiple-of style lint. The author replaced only the constant-divisor predicate with is_multiple_of. The second capture reran the affected 11 tests on final production source and passed formatting and all-target Clippy. Both attempts, command streams, source before/after hashes and the original failure remain retained. Source was unchanged during each run; every final executed input matches its committed blob. Independent source review accepted final source and the narrow lint correction.

Tests use manually constructed maps for marker objects, original source tokens for numeric expectations, and separate raw/ordered-tree/sorted-Value assertions. They cover marker placement/nesting, phantom-node strings, Unicode/escape identity, malformed adjacency and invalid surrogate strings, escaped duplicate keys, exact and one-less limits, pre-copy refusal ordering, admitted depths 208/256 and cancellation in long-token/whitespace/node paths. This is reusable JSON authority, not a second semantic engine. The formatted production file has 389 lines and the regression file 404, within the source review budget.
