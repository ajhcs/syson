# Flat layout API resource qualification

This development-only profiler measures actual `syson_layout::layout` on the named U10b candidate and separate direct `admit`→`place` controls. It does not assert that candidate is already merged.
Build the retained fresh Cargo package on `/workspace` with the exact serde_json1.0.151 and candidate path; the raw manifest/runner pin original execution paths rather than a portable launcher.
Run `u10b-profile NODES DENSITY [--cancel-before|--continuation|--budget-continuation|--cancel-between]`; default nodes are64/128/256/1024, densities1/2, and direct controls require64/1.
The current fixed drivers retain two warmups/seven measured observations per group, five real continuation/cancellation controls, five invalid-CLI cases and26 original library cases plus fmt/Clippy/WASM. All126 resource-driver and78 normally formatted library-driver lines count as authored verification code.
Both default1024-node cases refuse with Work; report refusal latency separately. Never relax quotas to meet a count target.
Counters precede verification, reference calls and JSON; signed live change, absolute/incremental peak and whole-process VmHWM remain distinct. Direct timing excludes admission setup.
The real continuation control retains admission work and its callback; the tightened-budget case detects a reset, while cancellation between phases requires zero new allocation requests.
Native geometry, actual measurement/routing/worker/UI, all-shape readability and supported capacity remain OPEN; seven measured samples do not justify p95.
