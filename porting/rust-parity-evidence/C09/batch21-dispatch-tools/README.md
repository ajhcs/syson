Descriptors are `{kind:"undefined"}`, `{kind:"null"}`, `{kind:"boolean",value}`, `{kind:"number",bits}` with 16 lowercase big-endian hex digits, `{kind:"string",value}` and `{kind:"array",items:[descriptors]}`.
