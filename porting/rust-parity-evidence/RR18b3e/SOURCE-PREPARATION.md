# RR18b3e source preparation

The flow under test is: import and select a long-named model element, read or copy its complete name in Selection, rename/undo/redo, then preserve visible draft or readonly focus through refusal and font-triggered cancellation without overriding deliberate scrolling.

Base: `c22c5b5fa664afc91c2d2d238fd766a60ba2f71f`. This composes the qualified C helper, C3 native CRLF draft repair and C2 consumer recipes; it is a review snapshot, not a merge destination. Existing explicit model/factory/graph holds remain untouched.

Write scope: `src/lib.rs` navigation/full-name fallback only, `web/loader.js`, `web/style.css`, `tests/rr18b3e_regression.rs`, and this unit's recipe/preparation directory. F owns `bounded_render.rs`; no product model or shared manifests are changed here.

Navigation keeps the full exact escaped name in the button's DOM/accessible name and class/kind on a separate visible line. CSS bounds its visual name to two lines. A visible hint identifies the full-name path: select the element, then use its native Element name control. The non-renamable branch gets a readonly Full element name native textarea. Neither branch silently substitutes a truncated name into the model. This is a targeted usability improvement; it does not establish whole native SysON tree/widget equivalence.

The loader takes the old viewport/focus visibility before replacing DOM, restores background page scroll, and keeps previously visible focus visible with nearest scrolling. A deliberately scrolled-away logical focus stays away on background work. Explicit actions still reveal their requested target. Canvas pan authority/cancellation barriers, draft quotas and the no-copy native-CRLF comparison remain unchanged.

Readonly native textareas keep only identity, owner/type/scope, selection/caret and control-local scrolling. Their value is regenerated by Rust and never copied into draft state. Inspector readonly focus requires the same selected model identity and document epoch, and enclosing stable disclosures continue through the existing disclosure cache. This supports F's stable `saved-value-{attribute}`/`saved-json-{attribute}` controls without touching F's production source.
