# Qualification packet assembly

Run the independently reviewed assembler only after root has retained a terminal resource-04/inner-01 epoch and generated ranges. It performs file I/O and read-only immutable Git blob lookup; it never runs the profiler, checker, compiler or subject. Its output is raw assembly, not feature acceptance.

The fixed capture includes both 34-case library epochs, actual resource attempts 01/02/04, the unexecuted attempt-03 source epoch, every other named preflight/source epoch, current tooling, all profile/build streams and receipts, the allocator whole source and exclusive generated 84-line include. Every recorded before/prepared/compiled/after input resolves to local archived bytes or a verified immutable blob from #183, #184, #186 or #190. Original epochs remain distinct; a matching hash permits byte reuse without transferring another workload's qualification.

Before publication the independent reviewer must inspect all 99 case outcomes and raw hashes, 2-warm/7-measured group ranges, null search metrics for admission refusals, strict Grid/quota/cancellation behavior, exact prepared/compiled/source bindings, actual resource attestation, process teardown and the complete recovery table. Refused preflights remain refusals; neither them nor assembly metadata establishes execution success.

A missing input, failed compile, unexpected case or recovery mismatch stops qualification and preserves the attempt before any repair. New runs require fresh reviewed paths and recounting. Root refreshes current source-budget/qualification metadata after source freeze, publishes the qualified tooling PR first, then binds the separate library PR to the immutable tooling/evidence revision. Native, fractional/UI, p95 and capacity acceptance stay open.
