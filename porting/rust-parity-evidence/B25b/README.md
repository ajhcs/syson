# B25b: bounded participant adoption

This adopts the complete participant that removes `source` and `target` from object-valued children of ConnectorAsUsage objects and supported subclasses. The original suite covers eight connector classes: ConnectorAsUsage and seven subclasses. Source comes from canonical corrected #104, head `d98994ae1b795ff38ad418ce2725f9cc3117b0bc`, preserving the original API and all 8 tests from PR #73. The active 12-case input packet and its source predictions remain byte-exact and count toward the review budget. Predictions are source-derived expectations, not fresh SysON observations.

The new actual-participant regression uses manually constructed marker-object expectations, original numeric lexemes and decoded duplicate namespace keys. It checks both migration/no-op paths, first-key position with final value, exact serialization/re-entry and the fixed version. Malformed suffixes and oversized edited private output refuse while a prior prepared result and source remain unchanged. These are private preparation checks, not atomic database publication.

`b25b_probe` times only the actual participant `prepare` call for 1/256/1024 groups; each group contains one ConnectionUsage. Fixture construction is outside timing. Every call produces a fresh owned result; complete expected JSON, row order/ordinal values, removal behavior, preserved parent fields, version and namespace-sensitive replay are checked afterward. Two warmups precede seven raw samples with min/median/max. Untimed replay occurs between calls, so these describe that warmed API context; no p95, native/UI speed, RSS/allocation or capacity claim follows.

Run `cargo test --offline --locked --manifest-path rust/crates/syson-migrations/Cargo.toml --test b25b --test b25b_literal` and `cargo run --offline --locked --release --manifest-path rust/crates/syson-migrations/Cargo.toml --example b25b_probe`. The new tests and probe are formatted; the [qualification packet](main-batch34/qualification.json) records execution and independent review when available. Timing ranges inform review without a hard cutoff.

The shared provider was admitted as B25S1; its parent acceptance remains open. B25d, the complete RR24 recipe and both RR22 preparation/wire literal gates remain mandatory. Fresh native comparison, full participant composition, independent stamps, semantic/representation publication, durable restart and default UI workflows are not accepted here. No existing hold is released.
