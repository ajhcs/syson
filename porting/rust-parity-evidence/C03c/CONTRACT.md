# C03c local prepared-project transport contract

The product API exports only `PreparedProject.wire()` through `encode(&PreparedProject)` and decodes into untrusted `ProjectInput`. Decode does not manufacture prepared state or interpret participant stamps. Real C03b preparation is required before publication. This is version 1 of a local candidate envelope, not a native SysON archive format.

The envelope names `format`, `documents`, and `representations`. Each document includes inline raw `json`, required `versions` (connector/annotation/view) and required nullable `references_version`. Each representation includes `kind`, inline raw `json`, and required nullable `control_version`/`diagram_version`. Every nullable key must be present; null is different from omission. Unknown and duplicate envelope/metadata fields refuse. Payload members, including duplicates, remain opaque transport.

RawValue preserves each complete JSON value-token byte range, including interior whitespace, namespace/member order, opaque integers and Unicode. Envelope separator whitespace is not payload data. Prepared wire currently has no whitespace outside its value extent; encoding refuses rather than silently trimming if that changes. Only payload bytes are promised byte-identical; envelope formatting and metadata string escapes are not preserved lexical forms.

Caps are64 combined items, 1 MiB/payload, 8 MiB aggregate payload, 1024 UTF8 bytes/kind or stamp and 10 MiB/envelope output. The outer cap accommodates worst-case metadata escaping without JSON-string escaping the payload again. Encoding buffers privately and exposes no partial bytes. Decode checks limits before producing owned ProjectInput. The candidate payload is transported, not admitted as a valid model/representation; C03b retains depth/value/model/version checks.

Proposed verification: nine integration tests plus a compile-fail prepared-only API example; actual prepare→encode→decode→prepare/replay, foreign-first pending stamps, foreign-kind future stamps, opaque numbers/Unicode/duplicate payload members, required nulls versus missing fields, metadata duplicates, future format, corruption/trailing data and exact byte/aggregate boundaries. Root executes against frozen source; these are proposals until captured. Native archive, SQL, framework-history, durable publication and global C03/C06/C07 acceptance remain open.
