# F33 selected JSON interchange

`Bundle::load` privately parses every supplied EMF JSON 1.0 document, checks the finite node family, then resolves every admitted wire reference using F04's actual immutable registry. Only a complete validated bundle is returned. Caller publication is an explicit assignment; no existing editor, resource, transaction, file or database is mutated. A later document/reference failure cannot publish earlier staging.

The admitted exact classes are Package, PartDefinition, PartUsage, PortDefinition, PortUsage, ViewDefinition, ViewUsage, OwningMembership, FeatureMembership and FeatureTyping. Only `ownedRelationship` and `ownedRelatedElement` hold selected containment nodes. FeatureTyping `type` resolves against Type and `typedFeature` against Feature; this is structural reference typing, without package/part semantic validity checks. Missing and null references remain distinct values. Present metadata-known reference features outside this whitelist refuse, including derived/empty values, rather than being silently accepted. Unknown envelope/node/data fields are retained as opaque JSON values. Their contents receive no reference or semantic interpretation.

Each resource has an explicit caller key and fragment policy. Bare UUID references always use the current document's JSON node identity. Selected typed/untyped sysmllibrary/kermllibrary UUID references use only the target resource's chosen fragment policy. Resource keys, node IDs and semantic elementIds remain separate. Duplicate resource keys, unknown classes, invalid/duplicate IDs, dangling references, unsupported wire forms and wrong target classes refuse. Unknown scalar validation, all other classifiers/reference features, ordinary resource/relative URI forms, discovery/loading and native serialization defaults/caches/notifications are excluded.

Save emits pretty JSON preserving parsed values, array order and all IDs/wire strings. Upload whitespace, original object key ordering, duplicate JSON object member spellings and number lexical spelling are not byte-preservation promises. Repeated load/save/reload retains values; handles from an earlier registry are foreign after reload. Bundles admit 1–32 resources, at most 1 MiB of UTF-8 JSON per resource for both input bytes and canonical saved bytes and 4096 total selected containment nodes. Parsing uses serde_json's enabled default recursion guard; it is not an unrestricted depth parser.

The native Batmobile fixture supplies actual selected class/reference examples. Pinned Ecore supplies structural feature types/containment. SysONJsonResourceProcessor delegates native serialization and handles relative ordinary-resource normalization that this adapter deliberately refuses. These source observations do not qualify the third-party EMF JSON runtime or the complete native file. Synthetic tests round-trip the admitted shapes and an actual F05-produced external GeneralView reference. Full Batmobile contains other classifier/reference families and is not claimed admitted.

F33 targets F05, which already contains exact F04 blobs. Land prerequisites first, retarget to integration, inspect and rerun checks. Never merge into a prerequisite feature branch. Source-only worker ownership excludes existing model/graph/factory paths and integrator-owned manifests/locks. No native SysON/Syside/EMF runtime, network, filesystem resource loading or database operation is performed.
