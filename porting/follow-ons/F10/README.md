# F10 primitive AST values

`syson-ast-values` now implements the pinned primitive dispatch contract as an independent std-only crate. Undefined, null and present values remain distinct. Each converted value borrows its exact raw lexeme and byte span. String results contain UTF-16 units; conversion does not silently replace source-created lone surrogates with U+FFFD. Consumers must handle failed UTF-8 conversion explicitly.

Rule-name dispatch precedes declared-type dispatch. In particular, the reachable STRING_VALUE and UNRESTRICTED_NAME terminals preserve their quotes and escapes. The inherited STRING helper scans escapes rather than using JSON decoding; ID removes one leading caret and REGEXLITERAL follows JavaScript substring bounds. Syside name sanitation and escaping are separate operations with their distinct source escape sets.

Numeric strings accept explicit decimal grammar, ECMAScript whitespace, Infinity and unsigned binary/octal/hex forms. Invalid numeric strings yield an explicit Number(NaN), not a parse error or successful zero. Decimal parsing uses standard-library binary64 conversion after syntax validation. Radix integers perform one guard/sticky ties-to-even rounding instead of repeated floating-point accumulation. Overflow, subnormal values and signed zero remain f64 values. Raw spelling independently selects the Java translator's integer/rational class predicate. No JSON serialization is supplied: JSON null projection of nonfinite numbers belongs to a later layer.

BigInt and Date helpers are explicit unsupported outcomes; the pinned grammars declare no reachable return types for them. Dynamic non-ASCII dispatch names are rejected, a documented narrower domain than the inherited helper. Parsing, CST/rule resolution, ambiguity/recovery, AST construction, linking, semantic numeric metamodel quirks, Java attribute cleaning and semantic import remain separate. Candidate naming source correspondence beyond retained bytes is not claimed.

The API requires a UTF-16-unit limit and cancellation observer. Cancellation is checked before conversion, periodically while materializing units, and after conversion. Standard-library decimal parsing is bounded by the input limit but is not preemptible. Name escaping also bounds produced units. Errors retain the supplied source span; malformed spans are rejected.
