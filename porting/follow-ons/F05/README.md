# F05 selected ViewUsage construction

The adapter consumes one existing model transaction and returns it with one admitted ViewUsage subtree staged for the caller's commit. Membership, ViewUsage and FeatureTyping each receive a caller-provided NodeIds pair. JSON node IDs and semantic elementIds remain distinct. Public default-feature subtree admission checks spelling, concrete classes, containment and collisions in both identity domains; it does not prove UUID entropy, native factory storage or cache defaults.

The actual F01 planner runs against an attached initial projection, so existingElementsCount includes the new ViewUsage. A query provider materializes the actual prefix (declared name, composite flag, FeatureTyping allocation and attachment) in a temporary selected Document. F01 then queries the real ResourceSet over that prefix document and owned library document copies. The provider is internal; no caller-supplied plan, stale PrefixSnapshot or external target handle is replayed. Only the selected caseUsage/caseViewUsage effect family is accepted; other effects fail explicitly.

The finished subtree is appended once to the original transaction. Earlier temporary Editor commits publish only to private copies. A refusal consumes the transaction, including prior staged work, while the owning Editor remains unchanged. Success preserves prior staged work for one caller commit; model identity/revision checks reject foreign or stale commits. Cancellation is cooperative through a latched caller predicate, including source planner polls and a final check before admission.

Namespace parents are admitted. Type parents use FeatureMembership; other namespace parents use OwningMembership. Before any query, both membership and ViewUsage are attached in the private initial projection. Only a single FeatureTyping is added by the selected plan. Its typedFeature is encoded as the ViewUsage's local JSON node ID. A local GeneralView uses a local node ID; an external GeneralView uses a typed UUID library URI with explicit semantic-fragment policy. The emitted wire resolves through actual F04 registry/type checks against the same selected resource documents. Unsupported URI/fragment families and wrong identities refuse without semantic-ID fallback.

A present ResourceSet with no match assigns an explicit null type. WithoutResourceSet is a caller-declared projection context and also assigns null; supplied libraries are not searched in that mode. Reached unresolved import observations do not become absence. Native import evaluation, URI loading, inverse notifications, cache/lazy-field state, full EMF serialization, graphical representations and raw-factory qualification remain outside this adapter.

Seven pins and one actual Batmobile membership/reference identity example qualify the source contract. Coordinator validation passes 12 integration tests, formatting and scoped all-target Clippy. All 69 captured inputs match the executed bytes; the exact original runner and six raw command streams are retained under validation/f05-01. The unchanged initializer dependency emits its existing fetch_update deprecation warning; the new crate has no warning and scoped Clippy exits0. No native Java/EMF execution is attributed to source pin checks.
