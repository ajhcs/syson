# F04 selected reference contract

The pinned Batmobile template stores local noncontainment references as JSON strings matching a target node `id`, while target `data.elementId` differs. StandardViewDefinitions stores a typed `sysml:Namespace sysmllibrary:///UUID#UUID` reference. StandardLibrariesLoader explicitly enables default reference serialization to retain library `elementId` fragments; SysONIdentityService separately selects library elementId and delegates ordinary identities. The migration strips a leading type when present, calls ResourceSet.getEObject(uri,false), and preserves the URI prefix while replacing old fragments. This is source evidence, not an executed EMF oracle.

The adapter admits optional/missing or null references, bare UUID strings as local JSON-node IDs, and selected absolute `sysmllibrary:///UUID#UUID` / `kermllibrary:///UUID#UUID` strings with optional known `sysml:Class ` type prefix. UUID syntax is a bounded observed family; exact spelling/case is preserved. Registry keys are caller-owned identities, not instructions to load resources. Each resource explicitly selects JsonNodeId or SemanticElementId for external fragments. There is no fallback or inference from its scheme. Bare local strings always use JsonNodeId.

Relative URIs, resource-scheme forms whose producer constant remains external, percent encodings, structural/path fragments, empty/multiple fragments, arbitrary schemes, proxy objects and syson-import qualified-name proxies are outside this selected family. The local JSON processor rewrites some relative uploads, but that transformation and the external JSONResourceFactory/EMF URI parser are not reproduced here. NonContainmentReferenceHandler creates a separate syson-import qualified-name proxy family, also excluded.

Resolution uses only an immutable owned snapshot of supplied Documents. Results retain exact resource key, JSON node id and semantic elementId, and can be validated only by the producing snapshot. Known typed prefixes and caller expected classes use actual metamodel assignability. Missing/null is absent; malformed syntax, unsupported families, missing registry targets, class mismatch and stale snapshot are distinct. No native graph module is modified because those paths remain held. No filesystem/network/database loading, migration, mutation, inverse maintenance, serialization or full proxy parity is claimed.
