# F04: selected immutable reference resolution

`syson-references` decodes the selected EMF JSON reference family and resolves it only in caller-supplied immutable Documents. It is a separate adapter crate because the planned initializer-graph source paths remain under an existing lease. No shared graph source or feature manifest is modified.

The supported syntax and pinned producer/consumer evidence are recorded in CONTRACT.md and source-manifest.json. Bare UUID strings always select the current resource's JSON `id`. Typed or untyped selected library URI fragments use a per-resource explicit JsonNodeId or SemanticElementId policy, never a fallback or scheme guess. Exact resource keys, ID spelling and case are retained. The syntax result stays separate from semantic lookup; missing/null, invalid, unsupported, unresolved and wrong-type results are distinct. Known class prefixes and caller expected types both use the actual metamodel's assignability relation.

A successful Target exposes resource key, JSON node id and semantic elementId separately. Its constructor and snapshot token are private. Registry.target checks Arc pointer identity before returning the immutable target JSON node; another registry rejects the result even if its supplied documents are byte-identical. Documents are owned snapshots, so later edits to a caller's clone do not change the registry. Targets and process-local snapshot tokens are not portable persistence or wire identities.

Tests use the actual pinned Batmobile and StandardViewDefinitions files for node/semantic identity distinctions. A GeneralView lookup uses the actual native JSON object under an explicitly synthetic library registry key; that key is not asserted to be the native filename-derived URI. Equal IDs in separate resources, class-tag/caller-type mismatch, fragment-policy mismatch, unsupported proxy/path/percent/relative forms, exact case, unknown targets and foreign snapshots are covered.

This adapter does not load resources, follow reference chains, mutate models, migrate old IDs, update inverse references, implement native proxies or reproduce EMF URI normalization. The external JSONResourceFactory/EMF serializer/parser source and installed artifact correspondence remain unresolved. It exposes no implicit network/database/filesystem fallback. Ordinary resource-scheme references, relative upload rewriting and syson-import qualified-name proxy resolution remain excluded. Future linking/storage/native binding work must explicitly admit its own callers and source contracts.

The coordinator owns Cargo manifests/lock and compiler allocation. Exact commands, original streams and frozen input hashes are recorded in the validation packet after execution; unrun native/upstream checks remain unrun. A local pass is bounded Rust adapter qualification, with full SysON reference parity unverified.
