# F19C: measured browser canvas binding

This stage binds the geometry and controller stages to the existing Rust/WASM authoring UI. Layout canvas prepares the exact committed package/part model, computes via the real F15/F18/F17 composition and publishes on a separate cooperative callback. Rotate preview requires an existing canvas and applies the controller's first-selected-leaf policy. Unsupported classes, ports, nonpackage ownership, cross-parent typing and container rotation fail explicitly. The original linear preview remains available before layout and while semantic changes are staged.

The loader waits for document.fonts.ready and measures name-only DOM spans using the same14px system-ui font,24px line height and preformatted whitespace as the rendered SVG foreignObject labels. IDs and dimensions cross the existing string-field ABI. The captured canvas revision rejects measurements after model, selection or font-generation changes, including identical-byte document imports. Font loading/loadingdone/loadingerror events cancel queued requests. The Rust header is ceil(measured name height)+20 for a separate class-caption row; this whole-pixel policy is local canvas policy, not a native font/runtime attestation. There is no fake fallback measurement.

Two zero-delay callbacks separate compute and apply; cancellation is cooperative between phases and does not preempt CPU computation or use a worker thread. Canvas request paints and subsequent background paints preserve editable control drafts, focus, caret and open details. Semantic actions keep their existing form reset behavior. The App invalidates queued requests on successful selection/staging/cancel, and clears canvas history on committed model changes, semantic history application and imports.

Canvas undo/redo is labeled separately from semantic model Undo/Redo. The companion JSON export/import is separate from committed EMF JSON, bound to its exact canonical model bytes and constrained by the controller's default1MiB file/escaped-ABI budget. Imported geometry is file data validated for schema, identity, integer nodes/headers and half-unit orthogonal endpoints; import does not attest fresh measurement, containment, obstacle optimality or native source geometry. Invalid import preserves publication/history/pending work.

The SVG uses published node positions/sizes and incident typing routes. Its view bounds include all nodes and route points, including negative/outside routes admitted from a file. Routes paint over node backgrounds. Selective rotation retains unselected parent geometry; a rotated child can exceed its unchanged package until Layout canvas recomputes package bounds. Full layout retains user-size minima under the F15 policy, so a narrow rotated leaf may grow to its minimum width. These explicit finite policies do not establish native graphical editor parity.

The browser script uses the installed Playwright workflow because the required Browser plugin/skill is absent. It exercises the actual WASM UI with a deterministic clock, preserves unsaved drafts across request/compute/apply, cancels queued compute and stale publication, checks font-event invalidation, rotation/incident edges, separate history, atomic imports, negative route fit and same-byte model-import generations. The existing authoring/scalar assertions are unchanged; their only edits block service workers and deny external requests before navigation. Runtime captures and screenshots are produced only by the coordinator, outside the repository, then source-bound receipts are retained here.
