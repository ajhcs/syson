# F34 finite package/part textual export

This companion to F14 accepts a complete selected-model Document and returns a complete owned UTF-8 string. The whitelist is named root/nested Package, PartDefinition and composite typed PartUsage, one-target OwningMembership/FeatureMembership, and exactly one local FeatureTyping per usage. Member order is preserved. No writer, file, transaction or partial output is published.

Pinned `SysMLElementSerializer` cases provide `package`, `part def`, `part`, ` : ` typing, semicolon and brace/body formatting. `Appender` and actual `syson_domain::names::printable_name` supply the printable-name rule. Options explicitly select LF or CRLF and zero to eight spaces/tabs indentation; output has no BOM or final newline. The empty model yields the empty string. This explicit byte policy is independent of host defaults.

The native serializer injects an INameDeresolver. The finite adapter chooses the shortest UTF-16-length suffix of a target's containment path that resolves to that exact declaration from the usage's lexical parent. The first segment searches nearest scope then ancestors; later segments search only the matched declaration. The selected FileNameDeresolver direct/ancestor/shortest branches are source-pinned. Its complete visible-import, alias, access, short-name and cache machinery is not implemented. If every candidate is shadowed, export refuses rather than binding a different target.

The input contract is the actual F14/model projection: `FeatureTyping.type` and `typedFeature` are semantic elementIds. Native bare node-UUID references, library URIs, dangling or wrong-class targets, multiple types, missing types, wrong membership kinds and unsupported classifiers refuse. The exporter never guesses between identity domains. JSON identities are intentionally absent from textual output and are allocated afresh on reload.

All fields outside the explicit envelope/node/data whitelist refuse, including declarations with short names, comments, modifiers, future fields or imports. Apostrophes, backslashes, control characters and empty names refuse because current F14 Java-compatible quote cleaning cannot establish a lossless roundtrip for them. Spaces, Unicode and native keywords pass through the actual printable helper. Broader F11 conservative reserved words can remain unquoted by the native helper; the final actual F14 gate explicitly returns NotImportable for those inputs. This conservative admission restriction is separate from native serializer behavior.

Before returning bytes, export imports them through the actual F14 importer into a private empty editor with at most 1,024 ephemeral supplied identity pairs. It compares declaration class/name/parent and the referenced declaration index, independent of IDs, then cancels private staging. No IDs escape. This gate also retains the actual parser's size/depth/token bounds. The exporter itself bounds declarations to 256, depth to 64, and output to 65,536 bytes. No caller model is changed on success or failure.

Nine exact source pins are checked by `python3 porting/follow-ons/F34/check_sources.py`. Native Java/Syside application execution and all other textual dispatch families remain unrun or unsupported; local Rust checks do not establish full export or SysON parity.
