# API source inventory candidate

This is a bounded declaration/contract inventory, not API implementation or complete inherited behavior closure. inventory.json preserves exact pinned source bytes by hash,15 local data-fetcher declarations,4 local SDL documents and18 documented REST operations. Counts are unlike units and are not a feature denominator. No server, upstream source, compiler, network probe or authentication attempt was executed.

The inherited Sirius source pin is a candidate whose resolved Maven/npm artifact correspondence remains unproven. Selected source includes REST controllers/default versioning, editing-context processing and WebSocket DTOs/handlers. Local SDL composition and delegate registration still need source/runtime closure. A Mutation field annotated QueryDataFetcher must not be renamed or treated read-only based on annotation spelling.

The source contracts preserve non-obvious behavior: object traversal omits implied Relationship objects without pruning their descendants; relationship results use a HashSet with no proven stable order. SysON createCommit delegates to a current-state amend implementation, while deleteBranch delegates getBranchById. Commit-change filters and by-ID null conditions differ. These details are not silently corrected in a port proposal.

WebSocket keepalive/session/subscription storage, stop/close cleanup and malformed messages remain independent obligations. The candidate terminate-message branch constructs its handler without calling handle, whereas connection close calls handle. That source difference is preserved for qualification. Editing-context event work waits on Future.get and has explicit shutdown/interruption/disposal behavior; ordinary synchronous Rust unit tests would not prove these lifetimes.

Authentication, authorization, session/cookie/CSRF/origin and project isolation are retained as unresolved required contracts. A bounded token/path search did not establish those contracts; no missing search result is treated as proof that checks are absent. Deployment/proxy policy remains part of the closure.

The next two proposed splits close exact wire dispatch/DTO/error and WebSocket lifecycle contracts before implementing them. No broad server rewrite or new runtime dependency is authorized by these proposals. Distinct source review, full inherited source/artifact mapping, actual wire behavior and real-user/full-application acceptance remain pending; inventory_complete is false.
