# Bounded Rust checkpoint M7

This checkpoint adds a complete static metamodel registry, typed scalar editing in the Rust/WASM authoring preview, source-backed construction capabilities and a Rust grammar/CST foundation. Full SysON user/API/data parity is **not achieved**. The three strict behavior-ledger rows remain unrun overall and zero are verified. The much larger source/dependency surface remains open.

## Implementation and independent review

The registry retains 182 domain classifiers (175 EClasses and seven enums), four custom-node classes, complete nested declarations and local inheritance/feature queries. It is declaration metadata, not implementation of the 70 operations, constraints or unresolved external ancestry. The independent exhaustive Ecore comparison is recorded in the validation lane.

Scalar mutation and the property inspector share strict type/capability rules. Independent reviews M4/M5/M6 cover 1,519 accepted scalar assignments across the known domain classes, all seven enums, 525 selected-constructor contexts and 36 polymorphic typing pairs. These synthetic contexts test the backing command rule, not abstract-class instantiation or whole-model semantic validity. Only three constructors are implemented. Multiline, saved CRLF/CR/NUL, generic rename and advertised action discrepancies found during review were corrected and retested. See [scalar review](validation/M4-SCALAR-INDEPENDENT-REVIEW.md), [UI review](validation/M5-UI-CAPABILITY-REVIEW.md), and [construction/text review](validation/M6-CONSTRUCTION-TEXT-INDEPENDENT-REVIEW.md).

The Rust syntax library loads complete pinned candidate grammar DATA and performs lexical and generalized Earley recognition with explicit CST action/assignment/reference markers, source positions, cancellation and work/memory budgets. Every success explicitly carries `SemanticStatus::NotPerformed`. All 735 source declaration parity rows remain `UNPORTED`. This does not implement Chevrotain decision/recovery behavior, AST construction, linking, semantic validation or SysON import. [Independent syntax review](validation/M7-INDEPENDENT-REVIEW.md) found no confirmed defect within that bounded contract; see [syntax contract](syntax/README.md).
