# Model navigation and property disclosure audit fix

The fresh desktop/mobile audit showed unnamed memberships and typing objects mixed with packages/parts at one level, and a long stack of secondary property forms. The model list now nests semantic children by actual owner. Relationship objects remain selectable in a labeled native disclosure that opens when one is selected. Native lists retain ordinary Tab/button keyboard behavior; no unsupported ARIA tree keyboard pattern is advertised.

Common short-name, abstract/composite, direction, body and literal-value controls stay visible. Other editable properties are grouped under More properties; read-only/unavailable values and the identifier remain accessible in separate disclosures. All original property forms and model capabilities remain present. Rust keeps an advanced editing origin open through stage/commit/cancel, including a rejected second action or same-element reselection. A staged edit refuses selection of a different element so committing A cannot appear to edit B.

The existing design now has 44px minimum control targets, bounded 36px visual indentation, wrapped actions and 320px document reflow. Canvas instructions describe the next user action. Model semantics, identities, history, raw factory and loader code are unchanged. Small mobile diagram-label readability and canvas zoom/fit remain separate work.

Final nav-03 passes 44 tests, formatting, scoped all-target Clippy and release wasm32 build. All 98 final captured source inputs match the committed source. Four real browser journeys passed against nav-02; the changed keyboard/accessibility inspector journey reran and passed against final nav-03. It covers 1365px desktop, 390px and 320px mobile widths, hierarchy/relationship selection, advanced-origin focus, wrong-B selection during A staging, live-region/AX continuity, no page overflow and measured 44px targets. Original streams and exact runners are retained. Screen-reader speech and cross-browser/touch-device usability remain unqualified.
