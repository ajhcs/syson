## Blocking source decisions

1. Obtain/pin the Sirius Web, Sirius Components, EMF JSON and Syside source/artifact inputs used at baseline, including snapshot resolution (`sirius.emfjson.version=2.5.5-SNAPSHOT`). Local SysON source cannot establish full inherited contracts or transitive license coverage.
2. Establish an approved reference build environment matching manifest/runtime requirements; no builds or dependency downloads were attempted in this lane. Integrator reports Maven absent from PATH, Java26.0.2.1 and default Node18.19.1/npm9.2.0 differing from manifest. An existing isolated Node24.21.0 runtime is available at `<existing-node24>/bin`; it still differs from manifest Node24.20.0. No package installs were performed; reference oracle remains unrun.
3. Freeze wire and storage fixtures before selecting Rust runtime/framework dependencies. Preserve UUID algorithms, JSON omission/null distinctions, schema extension points, library IDs, and source quirk dispositions.
4. Decide third-party scope explicitly: Rust application/WASM implementation can use external PostgreSQL and browser platform; JS parser/layout/widget runtimes cannot be hidden under generated glue. Dependency candidates require lockfile/license/runtime review before acceptance.
